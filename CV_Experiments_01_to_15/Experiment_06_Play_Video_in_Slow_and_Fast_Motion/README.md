# Experiment 6: Play Video in Slow and Fast Motion

## Aim
Read a video and display it in slow motion and fast motion.

## Requirements
Install dependencies from the root folder using:
```bash
pip install -r requirements.txt
```

## Run
From this experiment folder:
```bash
python main.py
```

## Notes
- Image-based experiments use `../sample_image.png`.
- Video-based experiments use `../sample_video.mp4` when included.
- Press `q` to exit video windows; press any key only where the program waits for a key.
- Output images are saved in this experiment folder where applicable.
